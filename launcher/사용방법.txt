2027 카운트다운 런처 1.2.0
Windows 10/11 · 64비트 · 단일 portable EXE

1. 쓰기 가능한 폴더에서 EXE를 실행합니다.
2. Microsoft 계정 버튼이나 플레이를 누릅니다.
3. 런처 안의 Microsoft 페이지에서 로그인합니다.
   인증 코드 입력을 요구하면 상단의 복사 버튼을 사용합니다.
4. 필요한 게임 파일과 모드는 자동으로 설치합니다.
5. 메모리는 설정에서 변경합니다.

플레이를 누르면 Minecraft 실행 후 saebyeok.iptime.org 서버에 자동 접속합니다.
게임은 Minecraft 26.3 / Fabric / Java 25로 고정되어 있습니다.

게임과 설정은 EXE 옆의 2027-Launcher-data에 저장됩니다.
Minecraft Java Edition을 플레이할 수 있는 계정이 필요합니다.
다른 PC나 Windows 사용자에서는 다시 로그인합니다.

Windows 실기 실행, 실제 계정 로그인 완료와 서버 접속은 검증 전입니다.
운영자 구성과 빌드 방법: 소스 ZIP의 README.md
