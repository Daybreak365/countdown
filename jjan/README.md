# 짠

복셀로 지은 작은 술집에서 잔을 부딪히는 웹 게임.
혼자 바에 앉아 바텐더랑 짠 하거나, 방을 만들어 친구들과 온라인으로 짠 할 수 있어요.

## 바로 하기

**https://jjan.onrender.com**

친구에게 게임 안의 "초대 링크 복사" 링크를 보내면 어디서든 같이 들어올 수 있어요.
초대 링크로 들어오면 첫 화면에 그 방이 먼저 나와서, "이 방에 들어가기" 한 번이면 돼요.
무료 서버라 15분 동안 아무도 없으면 잠들고, 그다음 첫 접속은 1분쯤 걸려요.

GitHub `main` 브랜치에 올리면 Render가 알아서 새로 배포해요. (설정은 `render.yaml`)

## 내 PC에서 실행

```
npm install
npm start
```

브라우저에서 http://localhost:3000 을 열면 됩니다. (Node 18 이상)

- 같은 와이파이의 친구는 `http://<내 PC의 IP>:3000` 으로 들어오면 됩니다.
- 포트는 `PORT` 환경 변수로 바꿀 수 있어요.

## 하는 법

- 잔을 꾹 누른 채 끌어서 바텐더 잔(혼자 짠)이나 친구 잔(같이 짠)에 부딪히면 그때 소리가 나요.
  세게 부딪힐수록 소리가 크고 술이 튀어요. 잔 재질마다 소리가 달라요.
- 혼자 짠: 바텐더가 손으로 직접 만들어 내 잔부터 따르고, 그다음 자기 잔에도 같은 걸로 따라요.
  손님 잔을 바텐더 앞으로 가져가 따른 다음 손님 앞으로 밀어 줘요. 한 손으론 병을, 다른 손으론 잔을 잡고,
  맥주는 잔을 기울여 받아요. 손이 안 닿으면 허리를 굽혀 바 위로 숙이고, 팔은 몸통을 뚫지 않게 바깥으로 굽혀요.
  칵테일은 한 번 만들어서 두 잔에 나눠 따라요. 잔을 들면 마주 들어 주고, 마시면 따라 마시고, 말을 걸면 대답해요.
- 같이 짠: 방을 만들 때 탁자와 자리를 골라요. 들어오는 사람도 빈자리를 골라 앉아요.
  - 바 테이블(2명) · 사각 테이블(4명, 마주 보고) · 원형 테이블(8명) · 긴 테이블(12명) · 큰 원탁(12명) · ㄷ자 단체석(16명, 바를 보고 둘러앉기)
  - 자리마다 잔과 안주 접시 사이를 넉넉히 둬서, 사람이 꽉 차도 옆 사람 안주와 내 잔이 겹치지 않아요.
  - 자리가 다 차면 다음 사람이 들어올 때 한 단계 큰 탁자로 다 같이 옮겨 앉아요. (옆자리·맞은편은 그대로)
    바 → 사각 → 원형 → 큰 원탁 → ㄷ자, 긴 테이블 → ㄷ자. 최대 16명.
- 아래 버튼: 술 바꾸기 · 안주 · **마시기**(가운데) · 채우기 · 해장. 말풍선 버튼으로 건배사.
- (지금은 꺼 둠: `public/js/main.js`의 `EMOJI_ON`을 `true`로 바꾸면 다시 나와요)
  건배사 줄 맨 앞 😀 버튼: 이모지 반응. 누르면 내 잔 위에서 톡 튀어나와 둥실 떠올라요.
  - 쟁반에는 최근에 쓴 8개(처음엔 👍 😂 🥴 😍 👏 🔥 😭 🍻)와 **전부** 버튼.
  - **전부**를 누르면 유니코드 이모지 15.0까지 1,870개 전부를 묶음(표정 · 사람·손 · 동물·자연 · 음식·술 · 여행·장소 · 활동 · 물건 · 기호 · 깃발)으로 골라요.
    - 찾기 칸에 한국어로 찾아요 (맥주, 하트, 고양이 …, 영어 이름도 돼요). Enter를 누르면 맨 앞 이모지를 보내요.
    - 찾기 칸에 이모지를 직접 넣어도 (휴대폰 이모지 자판, 붙여 넣기) 그대로 보낼 수 있어요. 목록에 없는 새 이모지도.
    - ✋ 버튼으로 피부색을 고르면 손·사람 이모지에 입혀요. 고른 색과 최근 쓴 이모지는 브라우저에 기억해요.
    - 국기는 윈도우에서는 글자 두 개로 보일 수 있어요 (윈도우 이모지 글꼴에 국기가 없어요).
  - 같이 짠은 방 사람 모두의 화면에, 그 사람 잔 위로 떠요. 연달아 눌러도 되지만 3초에 8개까지만.
    이모지가 아닌 글자는 서버에서 버려요.
  - 혼자 짠은 바텐더가 얼굴 옆에 이모지로 받아 줘요. (😂 → 🤣, 🥴 → 💧, 😭 → 🤗, 그 밖엔 따라 하거나 웃어 줘요)
  - 쟁반 밖을 누르거나 6초 동안 안 누르면 닫혀요.
  - 마시기를 톡 누르면 한 모금, 꾹 누르고 있으면 버튼이 차오르다 다 차면 원샷. (키보드는 Shift+Enter)
- 마실수록 취해요. 술마다 도수와 잔 크기로 들어간 알코올을 셈해서 화면이 점점 흔들리고 기울고,
  가장자리가 붉어지고, 잔을 끌 때 손이 떨리고, 많이 취하면 딸꾹질을 해요. 오른쪽 위 칸이 취기(말짱 → 만취).
  시간이 지나면 천천히 깨고, 창을 닫았다 와도 그동안 깬 만큼만 남아 있어요.
  같이 짠에서는 취한 친구 이름표가 붉게 흔들려요. 바텐더도 같이 마시면 볼이 빨개지고 몸이 흔들려요.
- 해장 버튼: 컨디션 · 여명808 · 헛개수 · 상쾌환 중 하나를 쭉 마셔서(알약은 털어 넣어서) 취기를 확 내려요. 20초에 한 번.
- 오른쪽 위 스피커 버튼: 소리 크기, 음악, 가게 소리, 음소거. 첫 화면에서도 바꿀 수 있어요.
- 안주 접시를 누르면 한 입. 다 먹으면 조금 있다 다시 채워져요.
  - 남의 접시를 누르면 한 입 뺏어 먹어요. 조각이 내 쪽으로 날아오고, 뺏긴 친구 화면에는 "OO 님이 내 안주를 뺏어 먹었어요!"가 떠요.
  - 혼자 짠에서는 바 오른쪽에 바텐더 몫 안주가 있어요. 몰래 집어 먹으면 한마디 하고, 몇 번 뺏기면 바텐더도 내 안주를 하나 집어 가요.
- 위쪽 **둘러보기**(눈) 버튼: 앉은 의자 눈높이에서 끌어서 고개를 돌려 가게를 구경해요. 휠로 당겨 보고, 화살표 키로도 돌아요.
  둘러보면서 노래 기물이나 안주를 누르면 그대로 써요. "자리로"(또는 Esc)를 누르면 원래 자리로 돌아와요.
- 이름은 화면에 보이는 폭으로 잘라요 (한글 7자, 영문 14자쯤). 보이지 않는 글자만 넣은 이름은 "손님"이 돼요.
  이름표가 겹치면 먼 쪽이 위로 비켜 서요.
- 왼쪽 위 **나가기**를 누르면 바로 나가지 않고 계산대에서 감열지 영수증이 뽑혀 나와요.
  - 마신 술(브랜드까지) · 안주 · 해장을 가게 값으로 적고, 합계 · 부가세 · 받을 금액, 그리고 "오늘의 기록"(짠 횟수, 머문 시간, 최고 취기, 같이 마신 사람, 뺏긴 안주)이 찍혀요.
  - 가게마다 값이 달라요. 편의점은 싸고(50원 단위), 루프탑은 비싸고, 다락방은 친구 집이라 "우정 할인 100%".
  - **이미지 저장**으로 PNG를 받고, 휴대폰이면 **공유하기**로 바로 보내요. **더 마실래요**로 돌아가거나 **계산하고 나가기**로 나가요.
  - 남의 안주를 뺏어 먹은 건 "서비스"로 0원. 가게 이름 · 주소 · 사업자 번호는 다 가상이에요.

- 노래 기물(또는 위 음악 버튼)을 누르면 신청곡 창이 열려요. 유튜브 · 유튜브 뮤직의 곡 링크를 넣으면,
  같이 짠에서는 방 사람 모두 같은 곡을 같은 자리에서 들어요. 일시정지 · 다음 곡 · 곡 빼기도 같이 움직여요.
  - 다른 사이트에서 틀 수 없게 막힌 영상은 알아서 넘어가요.
  - 브라우저가 자동 재생을 막으면 "눌러서 같이 듣기"가 떠요.
- 노래가 나오는 동안 기물이 연주하고, 판이 돌고, 파이프가 반짝여요.

## 술과 연출

7가지 분류, 64가지 술, 22가지 잔, 12가지 안주. 술마다 잔을 바꿔 담을 수 있어요.
술마다 실제로 만드는 방법대로 따라요.

| 만드는 법 | 술 | 연출 |
| --- | --- | --- |
| 흔들기 (셰이커) | 마가리타, 코스모폴리탄, 블루 하와이, 다이키리, 김렛, 위스키 사워, 에스프레소 마티니, 롱아일랜드 아이스티 | 재료 병을 하나씩 통에 붓고 → 얼음 → 뚜껑 덮고 짤랑짤랑 → 마개만 빼고 거름망으로 따르기 |
| 젓기 (믹싱 글라스) | 마티니, 네그로니, 맨해튼 | 얼음 먼저 → 재료 → 바 스푼으로 빙글빙글 → 스트레이너 얹고 따르기 |

직접 고르기 전엔 술에 어울리는 걸로 나와요. (막걸리엔 파전, 소주엔 두부김치, 와인엔 치즈)

레몬·라임·체리 같은 장식은 술을 다 만든 뒤에 톡 얹고, 마가리타의 소금 테두리는 처음부터 묻어 있어요.
먹을 수 있는 장식(과일, 올리브, 체리, 커피콩)은 마지막 모금을 마시면 집어 먹어요. 커피콩처럼 뜨는 건 마실수록 같이 내려가요.

같은 술도 실제 상품 중에서 고를 수 있어요. 병·캔 색과 띠 색으로 구분해요.

## 파일

- `server.js` 정적 파일 + 방 서버(WebSocket): 방 들여다보기, 자리 고르기, 탁자 키우기
- `public/js/tables.js` 탁자 종류와 자리 배치 (서버와 브라우저가 같이 씀)
- `public/js/data.js` 잔과 술 목록, 술마다 따르는 순서 (여기에 한 줄 넣으면 새 술이 생겨요)
- `public/js/glass.js` 잔 하나: 액체, 기포, 얼음, 따르기·칵테일 만들기 연출
- `public/js/props.js` 병, 캔, 셰이커 같은 그릇과 장식
- `public/js/anju.js` 안주
- `public/js/bartender.js` 바텐더: 따라 줄 잔 차례, 손(팔 IK)
- `public/js/game.js` 물리, 부딪힘, 카메라, 네트워크 동기화
- `public/js/room.js` 술집 복셀 모델, 탁자
- `public/js/decor.js` 가게마다 벽과 구석을 채우는 소품 (움직이는 기차, 진자, 비행기 …)
- `public/js/names.js` 이름 다듬기 (서버와 같이 씀)
- `public/js/barkeeps.js` 고를 수 있는 바텐더 (서버와 같이 씀)
- `public/js/audio.js` 소리 합성
- `public/js/receipt.js` 계산서와 영수증 (가게마다 값, 감열지 그리기)
- `public/js/emoji.js` 이모지 하나만 통과시키기, 피부색 입히기 (서버와 같이 씀)
- `public/js/emoji-data.js` 이모지 목록과 한국어 이름·찾는 말 (처음 "전부"를 열 때만 불러와요)
  - 한국어 이름과 찾는 말: [Unicode CLDR](https://github.com/unicode-org/cldr-json) (Unicode License v3)
  - 순서와 묶음: [unicode-emoji-json](https://github.com/muan/unicode-emoji-json) (MIT)
