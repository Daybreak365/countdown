# Discord 채팅 미디어 (1.2.24)

서버와 런처/클라이언트를 모두 1.2.21 이상으로 업데이트합니다. 기존 Discord 봇·채팅 채널 설정과 Message Content Intent를 사용하며 별도 OAuth 권한은 추가하지 않습니다. 새 버전 플레이어에게는 미디어 패킷을 보내고, 이전 모드는 텍스트 대체 메시지를 받습니다.

## 표시 방식

- 이미지 첨부는 보낸 사람의 메시지 아래에 작은 미리보기로 표시합니다. 최대 너비 128, 기본 높이 72 GUI 픽셀 안에서 비율을 유지합니다. 좁은 채팅창에서는 함께 줄어듭니다.
- 스티커는 `[Discord 아이콘] [프로필] [닉네임] │ [스티커]` 순서로 가로 배치합니다. 구분선과 스티커 영역은 현재 채팅 줄 간격 기준 3줄 높이이며, 프로필은 가운데 줄에 표시합니다. 스티커는 다운로드된 이미지의 실제 비율을 유지합니다. 가로로 긴 스티커는 남은 너비 안에 축소하고, 긴 닉네임은 필요할 때 말줄임표로 줄이며 마우스를 올려 전체 프로필을 확인할 수 있습니다. 여러 스티커는 각각 3줄 블록으로 표시하고, 함께 보낸 본문은 그 아래에 표시합니다. 다운로드 실패 시 기존 텍스트/원본 링크로 돌아갑니다.
- 커스텀 이모지 `<:name:id>`, 움직이는 이모지 `<a:name:id>`와 일반 Unicode 이모지는 문장 안에 표시합니다. 이모지의 표시 폭과 다음 글자까지의 이동 폭을 모두 8픽셀로 맞춰, 연속 이모지에 별도 좌우 여백을 더하지 않습니다. 사용자가 입력한 공백은 유지합니다. 일반 이모지는 Twemoji 이미지를 사용하며, 불러오지 못하면 원래 문자로 돌아갑니다.
- GIF/APNG는 프레임별 지연과 투명 영역을 합성해 반복 재생합니다. 표시 갱신은 게임 틱에 맞춰 최대 약 20fps입니다.
- 채팅을 열고 미리보기 또는 파일 이름을 누르면 Minecraft의 일반 링크 확인 절차로 원본을 열 수 있습니다. 자동으로 브라우저를 열지 않습니다.
- 채팅 스크롤·투명도·줄 간격을 따릅니다. 각 미리보기 줄의 텍스처 좌표를 나누어 다른 메시지와 겹치지 않게 합니다.
- 본문이 없는 이미지·스티커 메시지도 표시합니다. 나중에 오는 Discord 임베드는 기존 메시지에 추가하고, 수정·삭제는 최근 128개 서버 메시지/100개 클라이언트 메시지 범위에서 반영합니다. 이미 지운 게임 채팅을 뒤늦은 업데이트로 다시 만들지 않습니다.
- Discord에서 스포일러로 설정한 이미지/GIF 첨부는 처음에 `[스포일러 이미지 · 클릭하여 보기]`로 가립니다. 1.2.24 서버는 첨부의 `flags` 중 `IS_SPOILER` 비트(`1 << 3`)를 확인하고, `is_spoiler` 및 이전 `SPOILER_` 파일명도 처리합니다. 같은 첨부의 다른 CDN/프록시 주소나 임베드가 와도 가림 상태를 유지합니다. **서버도 1.2.24 이상으로 업데이트해야 합니다.**
- 채팅을 열고 가림 표시를 왼쪽 클릭(또는 일반 채팅 링크처럼 오른쪽 클릭)하면 해당 이미지 한 장을 게임 안에서 공개합니다. 공개 전에는 다운로드하지 않고, 공개 클릭은 브라우저를 열거나 서버에 명령/패킷을 보내지 않습니다. 공개 후 미리보기/파일 이름의 원본 링크는 기존처럼 작동하며, 다운로드 실패 시 파일 이름과 원본 링크가 남습니다.
- 스포일러 공개 여부는 메시지별·플레이어별로 유지합니다. 같은 이미지를 다른 메시지에서 보내면 다시 가려지고, 서버에서 수정해 다른 이미지로 바꾸거나 삭제하면 기존 공개 상태는 버립니다. 접속을 종료하면 공개 상태가 초기화됩니다. 미디어 표시 설정이 꺼져 있으면 기존 텍스트 표시만 사용합니다.

## 지원 형식

| 종류 | 표시 |
| --- | --- |
| PNG, JPEG 첨부 | 정지 이미지 |
| GIF 파일·움직이는 커스텀 이모지 | 애니메이션 |
| PNG/APNG/GIF 스티커 | 이미지 또는 애니메이션 |
| WebP/AVIF Discord 첨부 | Discord 이미지 프록시의 PNG 변환으로 정지 미리보기; 변환 실패 시 원본 링크 |
| Tenor/Giphy 및 Discord 이미지 임베드 | 제공된 이미지/GIF 미리보기 |
| MP4/WebM으로 제공되는 GIF 링크 | 임베드의 정지 썸네일을 사용하며 동영상 자체는 재생하지 않음 |
| Lottie 스티커 | 이름을 텍스트로 표시; Lottie JSON 렌더링 미지원 |
| PDF/일반 파일·지원하지 않는 형식 | 파일 이름 표시 |

한 메시지는 최대 6개 미디어 미리보기와 24개 인라인 이모지를 표시합니다. 파일당 8 MiB, 원본 한 변 4096픽셀/총 4메가픽셀, 애니메이션 200프레임 이하를 처리합니다. 200프레임을 넘는 애니메이션은 첫 프레임만 표시합니다. 표시용 이미지는 최대 192픽셀로 줄이며, 프레임 수가 많으면 메모리 한도에 맞춰 더 줄입니다. 전체 디코딩 캐시는 32 MiB로 제한합니다. 오래된 미리보기는 메모리 압박 시 텍스트/링크로 돌아갈 수 있습니다.

다운로드는 클라이언트가 Discord CDN/이미지 프록시, Tenor/Giphy 미디어 호스트와 Twemoji jsDelivr 경로에서 직접 수행합니다. 임의 호스트·로컬 주소·HTTP·리디렉션은 허용하지 않으며 봇 토큰이나 OAuth Secret을 보내지 않습니다. 파일은 디스크에 저장하지 않습니다. Discord의 서명된 첨부 URL이 만료되거나 외부 CDN 접속이 불가능하면 원본 링크/텍스트로 표시됩니다.

## 설정

- 서버 `config/newyearcountdown-discord.json`의 `showMediaInChat` (기본 `true`): `false`면 기존 텍스트 중계만 합니다. `/discord reload`로 적용합니다.
- 개인 `config/newyearcountdown-client.json`의 `discordMedia` (기본 `true`): `false`면 미리보기를 다운로드하지 않고 텍스트만 표시합니다. 파일 수정 후 게임을 재시작합니다.

## 검증과 출처

자동 테스트는 이미지 전용 메시지, 이모지 위치와 형식, 스티커, 서명 URL 유지, URL 제한, 늦은 임베드 병합, 패킷 직렬화, 다운로드 크기 제한, PNG 축소, GIF 재생 시간, APNG 부분 프레임/투명도/이전 프레임 복구, 채팅 줄 간격과 텍스처 연결을 검증합니다. 실제 게임의 GPU 표시와 실제 Discord CDN 다운로드는 접속 환경에서 별도 확인해야 합니다.
