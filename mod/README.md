1.2.33: 짠의 **든 잔이 탁자 크기·거리에 상관없이 같은 감도로 움직인다**. 전에는 화면 속 커서 자리(시선 광선이 탁자와 만나는 점)를 따라가서, 큰 탁자의 먼 쪽에서는 마우스를 조금만 움직여도 잔이 크게 튀었다. 이제 마우스를 민 만큼 탁자 위에서 그대로 움직인다(시선 1도당 2cm: 오른쪽 = 화면 오른쪽, 위 = 멀리). 클라이언트만 바뀌었다.

1.2.32: 짠의 **술 만드는 과정을 웹 원작 그대로** 옮겼다(순서·길이 동일, `JjanPour`). 그릇이 잔 옆에 나타나 준비 동작을 하고(샴페인 코르크, 캔 따기, 막걸리 뒤집기, 초록 소주병 회오리), 칵테일은 재료 병이 하나씩 와서 셰이커·믹싱 글라스·블렌더에 붓고 얼음을 넣고 뚜껑을 덮어 흔들거나 젓거나 간 뒤 따른다. 여러 술을 섞는 잔은 차례로 따르며 색이 섞이고, 층을 쌓는 술은 바 스푼 위로 가늘게 따른다. 다 따르면 장식을 톡 얹고, 폭탄주는 샷잔이 풍덩 빠지고, 소맥·와인은 회오리치고, 데킬라 선라이즈는 그레나딘이 가라앉고, 올드 패션드·모히토는 잔 안을 젓는다. 새 잔에는 얼음이 하나씩 떨어진다. **불붙는 술(B-52)은 부싯돌 소리와 함께 마인크래프트 작은 불꽃 입자로 붙고**, 잔을 들지 않고 빨대를 꽂아 단숨에 마시면 치익 하고 꺼진다. 준비 시간이 술마다 달라졌다(라거 2.8초, 재료가 많은 칵테일은 10초 이상). 서버와 클라이언트를 함께 올려야 한다.

1.2.30: 짠 화면을 **바닐라처럼 단순하게** 줄였다. 앉으면 오른쪽 위에 글자 세 줄(짠 횟수, 지금 술과 남은 양, 취기)만 보이고, 조작 안내는 앉은 직후 10초만 조준점 아래에 뜬다. 메뉴와 주문 화면은 바닐라 버튼으로 다시 만들었다(주문: 분류 버튼, 술 목록, 미리보기, 상품·잔 버튼). **든 잔이 미끄러지지 않게** 스프링을 단단하게 했다(출렁임 없이 커서에 바로 붙고, 멈추면 바로 선다). 서버와 클라이언트를 함께 올려야 한다.

1.2.28: 짠의 **잔 조작감을 웹 원작에 맞췄다**. 든 잔은 화면에서 마우스 커서가 있을 자리(탁자 위 든 높이)를 그대로 따라오고, 원작과 같은 스프링(빠르게 따라붙고 살짝 출렁임, 최고 4.2블록/초)으로 움직인다. 내 잔은 클라이언트가 프레임마다 미리 그려서 입력 지연이 없다(판정은 여전히 서버). `V`를 길게 누르고 있다가 떼면 잔을 내려놓는다(짧게 누르면 기존처럼 들기/내려놓기 전환).

1.2.23: Discord 스포일러 이미지는 채팅의 `[스포일러 이미지 · 클릭하여 보기]`를 누르면 게임 안에서 공개한다. 공개 전에는 이미지를 다운로드하지 않고, 선택한 메시지의 이미지 한 장만 해제한다. 공개 상태는 접속 중에만 유지하며 일반 이미지·스티커·채팅 링크는 기존 동작을 유지한다.
1.2.22: Discord 스티커를 `[Discord 아이콘] [프로필] [닉네임] │ [스티커]` 가로 레이아웃으로 표시한다. 스티커와 구분선은 채팅 3줄 높이를 사용하고 프로필은 수직 중앙에 정렬한다. 스티커 원본 비율을 유지하며, 연속 이모지의 추가 좌우 여백을 제거했다. 일반 채팅과 이미지 첨부 레이아웃은 유지한다.
1.2.21: Discord 채팅의 이미지·GIF·PNG/APNG/GIF 스티커를 채팅 미리보기로 표시하고 커스텀/일반 이모지를 문장 안에 표시한다. GIF/APNG는 재생하며 클릭하면 원본을 연다. 늦게 도착한 링크 미리보기와 수정·삭제도 기존 메시지에 반영한다. 비동기 다운로드·용량 제한·스포일러 숨김·텍스트 대체 표시를 포함한다. [지원 형식과 제한](docs/DISCORD_MEDIA.md).

## 디스코드 연동 (봇)
서버 안에서 디스코드 봇이 함께 돕니다. 따로 봇 프로그램을 띄울 필요가 없고, 토큰이 없으면 꺼져 있습니다.

- **프로필 사진**: 디스코드와 연동한 플레이어는 채팅과 탭리스트의 이름 앞에 디스코드 프로필 사진이 글자 한 칸 크기로 동그랗게 보입니다(채팅에서 마우스를 올리면 디스코드 이름). 온라인 모드 탭리스트에서는 기본 스킨 얼굴 자리에 사진을 표시합니다. 사진은 각 클라이언트가 디스코드 CDN 에서 직접 받습니다.
- **채팅 형식**: 일반 채팅과 디스코드에서 온 채팅은 사진·이름 뒤에 여백 있는 세로 그래픽 바를 두고 본문을 표시합니다. 귓속말·팀 채팅·행동 메시지는 원래 형식을 유지합니다.
- **계정 연동(필수)**: 연동하지 않은 플레이어가 접속하면 **월드에 들어가기 전에 연동 화면**이 뜹니다. **브라우저로 Discord 연결**을 눌러 로그인·승인하면 프로필이 표시되고 접속이 이어집니다. SDK 설치 없이 서버의 OAuth 설정만 필요합니다. **코드로 연동**에서는 기존 6자리 코드(10분)와 `/연동 코드:123456` 명령을 사용합니다. 필수 연동 화면의 제한 시간은 10분, 웹 인증 한 번의 제한 시간은 약 3분입니다. [웹 OAuth 설정](docs/DISCORD_OAUTH.md).
- 해제는 게임 `/discord unlink` 또는 디스코드 `/연동해제`(다음 접속 때 다시 연동해야 합니다). 한 디스코드 계정은 한 플레이어에게만 연동됩니다. 게임 안에서 `/discord link` 로 같은 화면을 다시 열 수 있습니다.
- 봇·웹 OAuth·Social SDK 서버 인증 설정이 모두 꺼져 있으면 접속을 막지 않습니다.
- **채팅 잇기**: `channelId`를 넣으면 양쪽 채팅이 전달됩니다. 디스코드 → 게임은 **Discord 아이콘 → 프로필 사진 → 이름 → 그래픽 바 → 본문** 순서입니다. 게임 → 디스코드는 `relayUsingLinkedProfiles=true`(기본)일 때 하나의 봇 소유 웹훅을 재사용해 **연동된 Discord 이름·@아이디·프로필 사진**을 메시지마다 적용합니다. Discord의 앱 표시는 유지됩니다. 웹훅 권한이 없으면 경고와 함께 기존 봇 메시지로 전송합니다. 접속·퇴장·서버 상태 알림은 봇 이름을 사용합니다. 디스코드 `/접속자`으로 접속자를 볼 수 있습니다.
- `/discord status` 로 내 연동 상태를(관리자는 봇 상태도), 관리자는 `/discord reload` 로 설정을 다시 읽고 봇을 다시 켭니다.

### 설정
웹 계정 연동은 [웹 OAuth 설정 안내](docs/DISCORD_OAUTH.md)에 따라 `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`, Redirect URI를 준비합니다. 아래는 채팅 중계와 코드 연동에 필요한 봇 설정입니다.
1. [디스코드 개발자 포털](https://discord.com/developers/applications)에서 애플리케이션을 만들고 **Bot** 탭에서 토큰을 발급합니다.
2. 채팅을 이으려면 같은 탭의 **Message Content Intent** 를 켭니다(꺼져 있으면 디스코드→게임 방향만 동작하지 않고 로그에 안내가 나옵니다).
3. **OAuth2 > URL Generator**에서 `bot`, `applications.commands` 범위와 **채널 보기·메시지 보내기·웹훅 관리** 권한으로 초대 링크를 만들어 서버에 초대합니다. 기존 봇은 채팅 채널의 웹훅 관리 권한을 추가하세요.
4. 토큰을 환경 변수 `DISCORD_BOT_TOKEN` 이나 `config/newyearcountdown-discord.json` 의 `token` 에 넣습니다(환경 변수가 우선). **토큰은 비밀번호와 같으니 공유하지 마세요.**
5. 채팅을 이을 채널의 ID(디스코드 개발자 모드에서 채널 우클릭 > ID 복사)를 `channelId` 에 넣고 `/discord reload`.

`config/newyearcountdown-discord.json`: `enabled`, `token`, `channelId`, `relayGameChat`, `relayDiscordChat`, `relayJoinLeave`, `relayServerStatus`, `relayCountdown`, `showAvatarInChat`, `showAvatarInTab`(탭리스트 사진, 기본 true), `promptLinkOnJoin`(접속 시 연동 화면), `requireLink`(연동 필수, 기본 true. false 면 "나중에 하기"가 생김). 연동 기록은 `config/newyearcountdown-discord-links.json` 에 저장됩니다.

### 표시 이름 편집 (OP 2 이상)
- `/displayname` 또는 `/표시이름`: 자신의 표시 이름 편집기를 엽니다.
- `/displayname Steve`: 접속 중인 대상의 편집기를 엽니다. 대상은 마인크래프트 계정 이름·UUID·설정한 표시 이름·연동한 디스코드 닉네임으로 찾습니다. 한글과 공백도 가능하며, 예를 들어 `/displayname 새벽 별`로 찾을 수 있습니다. 닉네임이 겹치면 계정 이름 또는 UUID를 사용하세요.
- 한 줄 입력창에 이름을 쓰고 드래그 또는 **Shift+방향키**로 원하는 글자를 선택합니다. **단색/그라데이션**, **보통/굵게**, 색상 견본 또는 `#RRGGBB` 값을 고른 뒤 **선택에 적용**을 누릅니다. 다른 구간도 같은 방법으로 따로 꾸밀 수 있습니다. **전체 선택**은 이름 전체를 선택합니다.
- 시작/끝 색상 옆 **팔레트**를 누르면 색상 선택기가 열립니다. 넓은 영역에서 채도·밝기를 드래그하고 오른쪽 색조 막대로 색을 고릅니다. HEX 직접 입력, 12가지 빠른 색상, 원래 색 복구도 지원합니다. 방향키로 미세 조절하고 Shift를 누르면 더 크게 조절합니다. **이 색상 사용**은 기존 선택 영역의 미리보기에 반영하며, **취소/Esc**는 색을 바꾸지 않고 편집기로 돌아갑니다. 끝 색상 팔레트는 그라데이션 모드에서 활성화됩니다.
- 입력창에 적용된 서식과 아래 채팅 미리보기를 확인한 뒤 **저장**합니다. 선택을 유지한 채 색상을 고르고 바로 저장해도 그 선택 영역에 적용됩니다. **Ctrl+Z** / **되돌림**, **Ctrl+Y 또는 Ctrl+Shift+Z** / **다시**로 텍스트와 서식 변경을 되돌립니다. **취소/Esc**는 저장하지 않고 닫고, **기본 이름**은 저장한 별명을 지웁니다.
- 그라데이션은 글자별로 색을 끊어 배정하지 않고 폰트의 실제 너비에 맞춰 글자 내부에서 연속으로 보간합니다. 한 글자도 양 끝 색상이 나타나며, 두 글자와 폭이 다른 글자도 같은 구간의 색 흐름으로 연결됩니다. 채팅·탭리스트·편집기 모두 같은 렌더러를 사용합니다.
- 이름은 한글 포함 최대 32자입니다. 서식 코드를 직접 넣지 않고 색상 버튼을 사용합니다. 바뀐 이름과 색상은 게임 내 새 채팅·탭리스트·디스코드에서 들어온 중계 채팅에 적용됩니다. 디스코드로 보내는 프로필 채팅의 작성자 이름은 연동된 Discord 이름을 사용합니다. 기존 채팅 기록과 실제 계정 이름은 유지됩니다.
- 표시 이름은 UUID별로 `config/newyearcountdown-display-names.json`에 저장되어 재접속·서버 재시작 후에도 유지되며, 디스코드 연동 해제와 별개입니다. 화면을 여는 명령뿐 아니라 저장 패킷도 서버에서 OP 권한을 검사합니다.

## 보신각 타종대 (블록)
- 크리에이티브 "기능 블록" 탭의 **보신각**을 들면 설치될 모습이 **홀로그램**으로 보입니다(청록색). 겹치는 블록이 있어 놓을 수 없으면 홀로그램이 **빨간색**이 되고 설치가 막힙니다. 구조물 전체(폭 13칸, 깊이 5칸, 높이 7칸)가 하나의 블록이며, 어느 부분을 부수든 통째로 무너지고 하나만 드롭됩니다. 정면은 설치한 사람 쪽을 향합니다.
- **당목(통나무)을 우클릭**하면 타종 모드: 카메라가 부드럽게 보신각 정면의 3인칭 시점으로 이동하고, 플레이어가 당목 뒤쪽 손잡이를 두 손으로 잡고 일직선으로 섭니다. 마우스를 왼쪽으로 당겼다가 오른쪽으로 휘두르면 당목과 함께 플레이어가 앞뒤로 움직이며 종을 칩니다. 빠를수록 크게 울립니다. Shift 로 나가기.
- 한 번에 한 명만 사용할 수 있고, 다른 사람은 사용 중 메시지를 봅니다. 다른 사람 화면에서도 당목·종 흔들림과 팔 자세가 보입니다.
- 새해(카운트다운 0)가 되면 설치된 모든 보신각이 자동으로 33번 타종합니다.
- 블록은 곡괭이로 캐면 아이템으로 돌아옵니다.

## 오미쿠지 뽑기대 (블록)
- 크리에이티브 "기능 블록" 탭의 **오미쿠지 뽑기대**: 가로 3 x 깊이 3 x 높이 4칸의 작은 사당 모양(돌 기단, 붉은 기둥, 기와 지붕, 제단 위 팔각 뽑기통, 새전함·방울·등롱·에마). 들면 설치 홀로그램이 보이고(청록/겹치면 빨강), 구조물 전체가 하나의 블록처럼 설치·철거됩니다. 물속에는 설치할 수 없고, 지붕은 계단식으로 밟을 수 있습니다.
- 어디든 **우클릭**하면 방울이 울리고 통이 흔들리며 막대가 튀어나옵니다. 앞에 운세 쪽지가 놓이고 지붕 위에 결과 글자가 떠오르며, 결과에 맞는 효과(파티클·소리)가 납니다.
- 결과는 채팅 대신 **운세 종이 UI**로 뜹니다(번호, 운세 등급과 한자, 총평, 소원/재물/연애 풀이). 등급은 좋은 순으로 대길·중길·소길·말길·평·소흉·중흉·흉·대흉 의 9가지입니다. 소원/재물/연애 풀이는 운세마다 5가지 문구 중 하나가 종이별로 정해집니다. **받기** 버튼을 누르거나 화면을 닫으면 종이가 화면 아래 인벤토리(핫바) 쪽으로 빨려 들어갑니다.
- **첫 뽑기가 메인**입니다. 이 월드(서버)에서 처음 뽑은 운세는 붉은색·금빛의 정식 종이("첫 뽑기")로 보관되고, 이후의 뽑기는 청회색 톤의 "추가 뽑기 N회차" 종이로 구분됩니다. 인벤토리의 오미쿠지 칸은 뽑기통 아이콘이고, 추가 뽑기 수는 +N 으로 보입니다.
- 받아 둔 운세는 **인벤토리 화면 왼쪽의 오미쿠지 칸**을 눌러서만 볼 수 있습니다. 맨 왼쪽이 첫 뽑기이고 오른쪽으로 넘길수록 나중에 뽑은 종이입니다(최대 50개). 더 넘길 수 없는 쪽 화살표는 비활성화됩니다.
- 기록은 **서버(월드) 저장 데이터**에 플레이어별로 저장됩니다. 그래서 다른 서버나 맵과 섞이지 않고, 다른 컴퓨터로 접속해도 같은 기록이 보입니다. 대길이 나오면 서버 전체에 알림이 갑니다.
- 한 번에 한 명씩 뽑고(약 6초), 연출은 근처 모든 플레이어에게 똑같이 보입니다. 도끼로 캘 수 있습니다.
- **관리자 콘솔**: 뽑기대 뒤편 가운데의 작은 붉은 버튼을 누르고 숨김 기능 비밀번호를 넣으면, 서버의 모든 유저와 뽑은 장수가 나옵니다. 유저마다 **이미지 저장**을 누르면 그 유저가 뽑은 오미쿠지 전부(표지 + 종이)를 한 장의 PNG 로 게임 폴더의 `omikuji_exports/` 에 저장합니다. 표지에는 이름과 함께 **그 유저의 스킨을 입힌 플레이어 모델**이 그려지고, 목록에도 유저 얼굴이 보입니다. 비밀번호는 서버가 다시 확인합니다. 이미지는 창 크기에 맞춰 그려지니 창을 크게 할수록 선명합니다.

## 소원 연등 (소원 빌기)
- 아이템 **소원 연등**(기능 블록 탭, 또는 종이 2 + 실 1 + 횃불 1 로 제작)을 들고 우클릭하면 **소원 쓰기 화면**이 열립니다. 소원을 적고(최대 60자) "연등 날리기"를 누르면 눈앞에서 연등이 떠오릅니다(크리에이티브가 아니면 아이템 1개 소모).
- 연등은 **3D 모델**(팔각 종이 몸통, 대나무 테두리와 십자 살, 일렁이는 불꽃, 안쪽에서 번지는 불빛, 꼭대기 매듭과 술)이고, 종이 위에는 **내가 적은 소원 글씨**가 보입니다. 처음엔 열기로 부풀며 천천히 뜨다가 점점 빨라지고, 바람에 흔들리고 천천히 돌며 높이 올라갑니다. 벽이나 천장에 막히거나 물에 닿으면 꺼집니다.
- 눈에 보이지 않을 만큼 높이 올라가면(발사 지점에서 약 190칸, 직전 45칸 동안 점점 작아짐) 연등은 사라지지만, **소원 기록은 서버(월드) 저장 데이터에 남습니다**. 인벤토리 화면 왼쪽의 **소원 기록 칸**(소원을 한 번이라도 빈 뒤 나타남)이나 조작 설정의 "소원 기록 열기" 키로 내가 빈 소원들을 최근 것부터 다시 볼 수 있습니다.
- **발사기**에 소원 연등을 넣고 레드스톤 신호를 주면 소원 글씨 없는 연등이 한 개씩 하늘로 날아갑니다(여러 개를 연달아 띄우거나 클럭 회로로 연등 쇼를 만들 수 있고, 소원 기록에는 남지 않습니다). 연등의 빛번짐은 배경을 가리지 않고 빛만 더해지도록 그립니다.
- 기록은 서버/월드별로 따로 저장되고, 다른 컴퓨터로 접속해도 같습니다.

## 세배
- **B 키**(조작 설정 "세배하기")를 누르면 남자 큰절 순서대로 절합니다(약 6초). 두 손을 이마로 올리고, 오른발을 딛은 채 왼 무릎·오른 무릎 순으로 꿇어 발뒤꿈치 위에 앉은 뒤, 두 손과 팔꿈치를 바닥에 대고 이마를 숙였다가 오른 무릎부터 세우며 일어납니다. 무릎·팔꿈치가 실제로 접히도록 플레이어와 갑옷 모델의 팔다리를 두 마디로 나눴습니다(평소 모습은 그대로). 동작은 주변 플레이어에게도 보이고(1인칭에서는 시점도 함께 낮아짐), 움직이면 취소됩니다. 땅 위에 서 있을 때만 할 수 있습니다.
- 5칸 안의 플레이어를 바라보고 절하면 그 사람에게 세배한 것으로 처리됩니다. 받은 사람은 행운 5분, 절한 사람은 세뱃돈으로 경험치 30을 받습니다. 보상은 같은 상대에게 하루 한 번입니다.

### 윷판
- 설치한 사람 쪽에 **붉은 양털(던지는 자리)** 이 오도록 3x3 으로 놓입니다. 어느 조각을 부숴도 판 전체가 치워지고 아이템은 한 번만 나옵니다.
- 규칙은 자동입니다. 판 위에 **누구 차례인지, 남은 이동(던진 결과), 던질 수 있는지**가 떠 있습니다. 빨강부터 번갈아 하며, 차례인 쪽이면 누구든 조작할 수 있습니다.
- **던지기**: 붉은 양털 우클릭. 윷·모는 한 번 더 던지고, 나온 결과는 '남은 이동'에 쌓입니다.
- **말 고르기**: 판 위의 우리 말, 또는 판 옆 대기 자리(빨강 왼쪽, 파랑 오른쪽)를 우클릭. 남은 이동이 하나뿐이면 바로 움직이고, 여러 개면 갈 수 있는 칸이 결과 이름(도·개·걸…)과 함께 빛나니 그중 하나를 누릅니다. 웅크리고 우클릭하면 선택 취소.
- 모서리나 가운데(방)에서 멈춘 말은 다음에 지름길로 꺾고, 같은 칸의 우리 말은 업혀서 함께 움직입니다. 상대 말이 있는 칸에 가면 잡아서 대기 자리로 돌려보내고 한 번 더 던집니다. 출발점(참먹이)을 지나면 골인, 네 말이 모두 골인하면 승리.
- 웅크리고 붉은 양털을 두 번 누르면 새 판. 판이 끝난 뒤에는 그냥 던지면 새 판이 시작됩니다.

## 컬링
- **컬링 하우스**(파랑·하양·빨강 양털)를 얼음 끝에 놓으면 바닥에 **5x5칸(반지름 2.5칸) 양털 픽셀아트 과녁**이 깔립니다. 블록은 얇고 충돌이 없어 스톤이 그 위로 지나갑니다. 과녁 위에는 **엔드·점수·차례·남은 스톤(●)** 이 떠 있고, 지금 점수가 나는 스톤 아래에는 금빛 고리가 깜빡입니다.
- **컬링 스톤**(빨강/노랑, 다듬은 안산암 2 + 염료): 우클릭을 꾹 눌러 힘을 모았다가(2초면 최대) 놓으면 바라보는 쪽으로 미끄러집니다. 모으는 동안 **예상 경로가 점선으로**, 멈출 자리가 고리로 보입니다. 그냥 놓으면 시계 방향으로 돌며 오른쪽으로, 웅크리고 놓으면 왼쪽으로 휩니다. 느려질수록 더 많이 휩니다.
- 얼음·꽁꽁 언 얼음·파란 얼음 위에서 잘 미끄러지고(파란 얼음이 가장 멀리), 다른 블록 위에서는 금방 멈춥니다. 스톤끼리 부딪히면 튕겨 나가고, 벽에 부딪히면 반쯤 튕깁니다.
- **컬링 브룸**: 꾹 누르고 있으면 앞쪽 3칸 안에서 미끄러지는 스톤 앞을 쓸어("쓸어라!"), 덜 느려지고 덜 휘게 합니다.
- **경기 규칙**: 4엔드, 엔드마다 팀당 스톤 4개. 빨강부터 번갈아 던지며, 차례가 아니거나 스톤을 다 던진 팀은 던질 수 없습니다. 스톤이 멈출 때마다 테이크아웃·버튼·중심까지 거리·과녁 밖 같은 결과와 현재 상황을 알려 줍니다.
- 8개를 모두 던지면 엔드 점수(가운데에 가장 가까운 팀이, 상대의 가장 가까운 스톤보다 안쪽에 있는 자기 스톤 수만큼)가 화면 가운데 제목으로 뜨고, 점수를 낸 팀이 다음 엔드를 먼저 던집니다. 스톤은 잠시 뒤 던진 사람에게 돌아옵니다(크리에이티브 제외). 4엔드가 끝나면 승리/무승부 발표, 그다음 던지면 새 경기.
- 하우스 우클릭: 점수 보기 / 웅크리고 우클릭: 주변 스톤 회수하고 새 경기. 스톤은 우클릭하거나 때려서 집을 수 있습니다.

## 새해 네컷 포토부스 (블록)
- 크리에이티브 "새해 카운트다운" 탭의 **2027 새해 네컷 포토부스**(철괴 2 + 레드스톤 램프 + 흰 양털 2 + 유리판 + 빨간 양털 2 + 그림)는 가로 7 x 깊이 7 x 높이 5칸, 실내 5x5 의 부스입니다. **안으로 걸어 들어가는 커다란 레트로 카메라** 모양으로, 크림색 몸체에 가죽 띠와 무지개 줄무늬, 정면은 렌즈 링 모양 입구(안쪽 커튼이 셔터), 지붕에는 플래시·셔터 버튼·뷰파인더, 뒷면에는 카운트다운이 보이는 LCD 가 있습니다. 찍는 순간 지붕 플래시가 번쩍이고 셔터 버튼이 눌립니다.
- 들고 있으면 설치 홀로그램이 보이고(청록/겹치면 빨강), 렌즈 입구가 설치한 사람 쪽을 향합니다. 구조물 전체가 하나의 블록처럼 설치·철거되고 곡괭이로 캐면 하나만 나옵니다.
- **정면의 렌즈 입구(커튼)를 우클릭**하면 부스 안 빈 자리로 들어가 카메라를 보고 서고, 촬영 화면이 열립니다. 걸어 들어간 뒤 안에서 아무 곳이나 우클릭해도 됩니다. 시점이 키오스크 카메라로 옮겨 가 **실시간 미리보기**가 되고, 가운데 밝은 틀이 사진 한 컷에 찍히는 영역입니다. HUD·이름표는 숨겨집니다.
- 촬영 화면에서는 **WASD 로 부스 안을 돌아다니고 Space 로 점프샷**을 찍을 수 있지만, 입구 커튼이 막혀 **이동키로는 밖에 나갈 수 없습니다. 나가기 버튼(또는 Esc)** 을 누르면 입구 바로 바깥으로 나갑니다.
- **포즈**(왼쪽): 기본 · 브이 · 손하트 · 꽃받침 · 냥냥 · 만세 · 쌍따봉 · 경례 · 팔짱 · 가리키기 · 당당(허리에 손) · 점프 · 앉기(앞줄). 팔꿈치·무릎이 접히는 두 마디 팔다리를 써서 손이 얼굴·턱·가슴 앞에 오도록 맞췄고, 바꿀 때 부드럽게 이어집니다. 다른 사람 화면에도 그대로 보입니다.
- **프레임**(오른쪽): 클래식 블랙 · 새해 레드 · 스노우 화이트 · 러블리 핑크 · 골드 파티 · 불꽃 밤하늘 · 색동 설빔(2027 정미년 붉은 양). 고르면 부스 안 배경벽과 커튼 색도 함께 바뀝니다. **필터**: 원본 · 뽀샤시 · 흑백.
- **촬영 시작**을 누르면 그 순간 부스 안에 있는 사람 모두가 함께 찍힙니다(다른 사람의 화면도 자동으로 촬영 시점으로 바뀝니다). 5초 뒤 첫 컷, 이후 6초마다 한 컷씩 **네 컷**을 찍고, 마지막 3초는 화면 숫자와 삐 소리로 셉니다. 컷 사이에 포즈를 바꾸거나 자리를 옮기세요. 카메라는 사람 키보다 조금 높은 곳에서 내려다보므로 앞줄이 앉으면 뒷줄 얼굴까지 함께 나옵니다.
- 네 컷은 600x1800 사진 띠 한 장으로 합쳐져 게임 폴더의 `photobooth/2027_photo_날짜_시각.png` 에 저장됩니다. 아래에는 2027 · HAPPY NEW YEAR · 날짜 · 함께 찍은 사람(영문 닉네임)이 들어갑니다. 결과 화면에서 사진을 보고 폴더를 열 수 있고, **부스로 돌아가기**를 누르면 다시 촬영 화면으로 돌아와 또 찍거나 나갈 수 있습니다. 채팅의 파일 이름을 눌러도 열립니다.
- 사진은 서버를 거치지 않고 각자의 클라이언트가 같은 시각, 같은 카메라로 찍어 각자 저장합니다. 그래서 게임 창이 최소화돼 있으면 그 사람의 사진은 만들어지지 않습니다. 화면 크기와 GUI 배율이 달라도 사진의 화각은 같습니다.
- 한 부스에서는 한 번에 한 촬영만 진행됩니다. 셔터·삐 소리는 `tools/sounds/photobooth.py`, 아이템 모델은 `tools/modelgen/m_photobooth.py` 로 만듭니다.

## 짠 (술자리 건배 테이블)
웹 게임 "짠"(`jjan/`)을 `jjan/docs/MINECRAFT_PORT_SPEC.md` 에 따라 옮긴 기능입니다. 인벤토리 아이템은 주지 않고, 잔과 술은 테이블 위 연출로만 존재합니다.

- 크리에이티브 "새해 카운트다운" 탭의 **짠 테이블 6종**: 바 테이블(2인), 사각 테이블(4인), 원형 테이블(8인), 긴 테이블(12인), 큰 원탁(12인), ㄷ자 단체석(16인). 들고 있으면 설치될 모습이 홀로그램으로 보이고(자리가 모자라면 빨간색), 도끼로 부수면 아이템 하나로 돌아옵니다. 조합법은 없습니다.
- **앉기**: 빈 의자를 우클릭. 바로 주문 화면이 열립니다. 분류 → 술 → 브랜드 → 잔을 고르고 **주문**. 닫아도 자리는 유지됩니다.
- **조작** (앉아 있는 동안)
  - 좌클릭: 한 모금 (공격·블록 파괴 대신). 소주잔·샷잔이나 샷 종류 술은 한 번에 비웁니다.
  - `V`(조작 설정에서 변경): 잔 들기/내려놓기. 잔을 들면 **시선은 고정**되고 잔이 **마우스 커서를 따라** 탁자 위를 움직입니다(웹 원작과 같은 느낌: 화면에서 마우스를 옮긴 만큼 잔이 따라옵니다). 다시 `V`를 누르면 잔이 제자리로 돌아가고 시선이 풀립니다. `V`를 **누르고 있는 동안만** 들었다가 떼면 내려놓을 수도 있습니다. 든 잔이 다른 사람 잔과 부딪히면 짠! 재질(유리·두꺼운 유리·크리스털·금속·도자기·나무)마다 소리가 다르고, 세게 부딪힐수록 크게 납니다.
  - `R`(변경 가능) 또는 **자기 잔 받침 우클릭**: 내 잔 메뉴 (한 모금·원샷·채우기·술 바꾸기·잔 들기·건배사·일어나기). 한 모금 버튼을 0.85초 누르고 있으면 원샷입니다.
  - `Shift`: 일어나기. 사망·텔레포트·접속 종료·테이블 철거도 같은 정리를 거쳐 자리가 비워집니다.
- **취기**: 마신 알코올만큼 오르고(무알코올·채우기·술 바꾸기는 오르지 않음) 시간이 지나면 깹니다(접속을 끊은 동안도). 말짱 → 기분 좋음 → 알딸딸 → 어질어질 → 만취 단계에 따라 이름표 색이 달라지고, 든 잔이 흔들리며, 가끔 딸꾹질을 합니다. `/jjan effects reduced` 로 흔들림을 줄일 수 있습니다.
- **명령어**: `/jjan menu|order|sip|shot|refill|raise|leave|status`, `/jjan effects reduced|normal`. 관리자: `/jjan table list`, `/jjan table inspect`(가까운 테이블 상태), `/jjan reload`(카탈로그 다시 읽기).
- **저장**: 자리와 진행 중인 잔은 저장하지 않습니다(재시작하면 빈 테이블). 마지막으로 고른 술·잔, 취기, 누적 짠 횟수, 효과 줄이기 설정은 월드에 플레이어별로 남습니다.
- 원작에서 가져오지 않은 것: 안주, 숙취 해소, 바텐더, 배경 음악, 영수증, 가격. 탄산 방울·김 같은 잔 안의 세부 효과도 줄였습니다. 술·잔·건배사 이름은 한국어뿐입니다.
- 술·잔 목록은 `tools/jjan/export.mjs` 가 원작 `jjan/` 의 데이터와 복셀 생성기에서 뽑아 `assets/newyearcountdown/jjan/catalog.json` 으로 넣습니다. 테이블 아이템 모델·블록 상태는 `tools/jjan/ItemModels.java`, 소리는 `tools/sounds/jjan.py` 로 만듭니다.

## AI 소원 엔진 — 첫눈
플레이어가 자연어로 소원을 빌면 AI(OpenAI Responses API, 기본 모델 `gpt-6.1-sol`)가 들어줄지 판단·협상하고, 필요하면 서버 안에서 실행되는 새 게임 로직(샌드박스 스크립트)을 직접 작성·검증·실행합니다. 퀘스트·능력·대화는 전용 UI(대화 화면 `G`, HUD `J` 접기)로 보이고, 세계의 사건은 기억으로 남아 이후 소원과 자율 사건에 이어집니다.
- 콘셉트: 한 해의 마지막 겨울에 내리는 **첫눈**에게 소원을 빈다. 화면과 HUD 는 크리스마스·연말 분위기(전나무색·붉은 테두리·금빛, 쌓인 눈, 호랑가시, 캔디케인, 꼬마전구, 내리는 눈)다. 이름은 설정의 **AI 이름**으로 바꿀 수 있고, 예전 기본값 `새벽별`을 그대로 둔 서버는 자동으로 `첫눈`이 된다.
- API 키: `/wishai gui` → **설정 → 세션 키**에서 임시 입력(OP 2 이상), 또는 서버 환경 변수 `OPENAI_API_KEY`. 임시 키는 입력한 관리자 접속 종료 또는 서버/월드 종료 시 삭제되며 파일에 저장하지 않습니다. 설정: `config/newyearcountdown-ai.json`.
- 소원 빌기: `G` 대화 화면, `/wish <소원>`, 또는 소원 연등.
- 관리자: `/wishai status|disable|enable|scripts|script|approve|wishes|memory|autonomy|selftest|...`
- 인게임 설정: `/wishai gui` → **설정**. 모델·추론 강도·예산·쿨타임·페르소나·자율 이벤트·기억·세계 변경과 실행 한도를 편집하고 **저장·적용**합니다(OP 2 이상). `*` 항목은 서버/월드 재시작 후 적용됩니다. 기존 서버의 모델 선택은 유지되므로 설정 화면에서 Sol로 바꿀 수 있습니다.
- 퀘스트는 완료 조건을 추적할 스크립트가 정상 시작된 후에만 HUD에 나타납니다. 준비·오류·승인 대기 중에는 표시하지 않으며, 제한 시간도 실제 표시 시점부터 셉니다.
- 커스텀 아이템 외형은 **GPT-Image-2.5 Flare**로 생성하고 투명한 16×16/32×32·최대 24색 픽셀 텍스처로 변환합니다. 설정 → **아이템 외형**에서 모델·품질·예산 예약을 조정할 수 있습니다. 같은 외형은 저장해 재사용합니다.
- 아이템·능력 키·전투·패시브 능력의 공통 `cooldowns` API는 서버에서 재사용을 제한하고 **액션바 위치에 아이콘·이름·남은 시간·진행 막대**를 표시합니다. 기존 바닐라 액션바 메시지가 있으면 위로 비켜납니다. 기존 수동 쿨다운 스크립트는 공통 API로 수정한 뒤 표시됩니다.
- 자세한 구조·스크립트 API·설정·시험 결과·제약: [docs/WISH_AI.md](docs/WISH_AI.md)
